# Getting started

## Install

Every download of 0.3.0 is on [its release page](https://github.com/fsegurai/arkenda-release/releases/tag/v0.3.0).

- Linux: the `.deb` (Debian, Ubuntu) and `.rpm` (Fedora, openSUSE) packages are the recommended downloads; the `.AppImage` runs anywhere.
- Windows: the setup `.exe` or the `.msi` from the release page.
- Android: the `.apk` (arm64, Android 7 or later) from the release page; later versions update from inside the app.
- Web: the app runs in a modern browser, with its notes in a browser vault.

## Your first vault

A vault is where your notes live. In the browser and on a phone, Arkenda starts with a vault of its own on the
device. On the desktop you can also open a folder as a vault: every note is then a plain Markdown file in that
folder, which other apps and tools can read too.

Read [Folder vaults](../guides/file-vault.md) for how notes are stored as files.
