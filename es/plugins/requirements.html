Requirements

What a plugin must have before it can be reviewed, and what is up to you. Most of the "must have" list is checked by the app when it installs your package; the rest is checked by a person during review.

Publishing to other users is not open yet. Today these requirements are the bar your plugin will be reviewed against once the marketplace opens; until then, meeting them is the best way to be ready. See Contributing a plugin.

Must have

Requirement Checked by Where it is specified
A valid manifest (arkenda-plugin.json, schema version 2), with no unknown field the app, at install Manifest reference, manifest.schema.json
A package that keeps the layout, file and size rules: one bundle, allowed assets only, 5 MB at most the app, at install The package, Limits
integrity that matches the bundle you ship the app, at install and at each load Integrity
Every permission declared, and each one explained by what the plugin does the app (declared), review (explained) Permissions and privacy
No network without network and its network.hosts; no data kept outside storage the sandbox, at every call Network hosts, ctx.storage
The sandbox rules kept: a plugin that hangs, floods or oversteps a limit is stopped the sandbox, while it runs The sandbox
activate done within 10 s, each command, button or Markdown block answered within 5 s the sandbox, while it runs Sandbox limits
No remote code: no eval, no code fetched at run time, nothing obfuscated; the source at repository builds to the same bundle review Security checklist
A license: an SPDX expression in license the app (present), review (matches the repository) license
A README with screenshots, in the package or at repository review Package layout (README and images are allowed assets)
Keyboard and screen-reader access: labels that say what each button does, nothing said by colour alone review UX guidelines ▸ Accessibility
Light and dark themes: views use the app's tokens; a theme keeps 4.5:1 text contrast the app (themes), review Design tokens and themes
English text for titles, labels and descriptions review Words and languages

Translations of a plugin's own text are not available yet: titles and view text show as written. When they are, Spanish (Costa Rica) and other languages will be welcome.
