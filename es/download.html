Descargar

Versión 0.5.3 · Novedades · Las actualizaciones se instalan desde la aplicación.

  • Su sistema

    Linux

    x86_64 · .deb, .rpm, AppImage

    Descargar .deb
    • .rpm
    • AppImage

    Prefiera el .deb o el .rpm: el AppImage incluye su propio WebKitGTK y es varias veces más grande. En Arch: yay -S arkenda-bin.

  • Su sistema

    Windows

    10 y 11 · x64

    Microsoft Store
    • Instalador (.exe)
    • .msi

    Los instaladores no tienen firma de código: SmartScreen puede advertirle la primera vez (Más información ▸ Ejecutar de todas formas).

  • Su sistema

    Android

    Teléfonos y tabletas · arm64

    Descargar APK

    Permita la instalación de aplicaciones desconocidas para la aplicación con la que lo descargue.

  • Su sistema

    Web

    Chrome, Edge, Firefox, Safari

    Abrir el área de prueba

    El área de prueba es la aplicación web con una bóveda de ejemplo que se queda en su navegador: sirve para probar Arkenda. Para guardar sus notas, descargue la aplicación.
