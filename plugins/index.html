Arkenda extensions

Build an extension with any tooling, language or layout you like. To be supported it must meet one contract: the manifest, the package, the entry point, the permission and sandbox rules, and the API version. The app checks all of it when it installs a package, and each problem it reports links to its rule in these pages.

Status (API version 1.2). Building a plugin and installing it as a development package from a file work today, and every release carries the command-line checker these pages call plugin-check (arkenda-plugin-check.mjs) and the starter template (arkenda-plugin-starter.zip). Not available yet: the marketplace (publishing a plugin for other users), signed releases and a published @arkenda/plugin-api package. See The package and release. Questions and ideas are welcome in the issues.
