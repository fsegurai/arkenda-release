Keyboard shortcuts

Arkenda's default keys follow the conventions shared by Google Docs, Word, Confluence, Notion, Obsidian and VS Code. Almost every key below can be changed or removed in Settings ▸ Keyboard, which also prints a cheat sheet; a key you set always wins over the default, and that page always shows the key that applies on the device you are using. A few are fixed: undo and redo, the task date, and F2 on a tab.

Keys are written for Windows and Linux. On macOS read ⌘ for Ctrl and ⌥ for Alt. On a phone or a tablet, the bottom bar, swipes, press and hold, and the back button do these jobs: see Phones and tablets.

Desktop app and web

Browsers keep some keys for their own windows and tabs (Ctrl+N, Ctrl+W, Ctrl+Shift+T, Ctrl+1 … Ctrl+9), and a web page cannot take them. So the web uses an Alt form of those keys, and "Go to tab" has no default key there (use the palette). Rows marked "same" are identical.

Tabs and panes

Next tab / previous tab Ctrl+Tab / Ctrl+Shift+Tab same
Move tab left / right Ctrl+Shift+PageUp / Ctrl+Shift+PageDown same

Ctrl+Tab order (Settings ▸ Editor ▸ Tabs, per device): Linear, the default, steps through the focused pane's tabs in strip order. Recent steps through them most recently used first: hold Ctrl and press Tab to go one tab further back (Shift+Tab one forward), and release Ctrl to stay on the tab shown, which becomes the most recent. A quick Ctrl+Tab switches between the last two tabs; Esc while Ctrl is still held goes back to the tab you started on. Each pane keeps its own order. The palette's Next tab and Previous tab follow the same setting.

Maximize pane and Restore panes have no default key; they are in the tab's menu, the note's … and the palette.

The editor keys are the same on the desktop app and the web.

Highlight, subscript, superscript, clear formatting, callouts and [[ note links have no default key: they are in the toolbar row, the selection bar and the palette, and you can give them one in Settings ▸ Keyboard. Clear formatting has none on purpose: its usual keys are taken (Ctrl+\ is the sidebar's, Ctrl+Space the editor's completion).

Keys the Markdown editor gave up

Ctrl+Shift+\ (jump to the matching bracket) and Ctrl+Alt+\ (re-indent the selection) do nothing in the editor: the panes use them.

Plugins

A plugin cannot take a key that a built-in action uses, nor Ctrl+K, Ctrl+P, Ctrl+O, Ctrl+Shift+P, Ctrl+Shift+F, Ctrl+\ and Ctrl+Shift+\.

Layouts and AltGr

Shortcuts match the physical key when Alt, Shift or your keyboard layout changes the character typed, so Ctrl+\ works on layouts where \ needs another key. A key pressed with AltGr is never a shortcut: AltGr types characters.

See also The desktop layout and Phones and tablets.
